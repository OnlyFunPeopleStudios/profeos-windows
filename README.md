# ProfeOS Windows - OnlyFunPeople Studios

Windows desktop build of ProfeOS, a comprehensive school management system for Argentine teachers.

## Features

- Complete school management
- Attendance tracking
- Grade management
- Student profiles
- Report generation
- Offline-first architecture

## Download

Pre-built Windows executable available in [GitHub Releases](https://github.com/OnlyFunPeopleStudios/profeos-windows/releases).

## Tech Stack

- Flutter (Windows Desktop)
- Dart

> **Note:** This repository contains the pre-built Windows executable. The source code is available in the [`profeos-app`](https://github.com/OnlyFunPeopleStudios/profeos-app) repository.
